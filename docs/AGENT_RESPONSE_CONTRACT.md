# Agent Response Contract

Every AI agent must return the following JSON structure.

```json
{
  "agent": "Machine Assessment",
  "status": "success",
  "summary": "Machine is healthy",
  "confidence": 0.92,
  "data": {
    "health_score": 91,
    "failure_probability": 0.08,
    "remaining_useful_life": "3.5 years"
  }
}
```

---

## Fields

### agent

Agent name.

Example:

- Machine Assessment
- Maintenance Intelligence
- ROI Analysis
- Decision Engine

---

### status

Possible values:

- success
- failed

---

### summary

One-line summary of the result.

---

### confidence

AI confidence score.

Range:

0.0 – 1.0

---

### data

Structured output generated by the agent.

Each agent can define its own fields inside data.
